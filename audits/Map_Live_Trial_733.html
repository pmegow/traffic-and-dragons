Failures turned into tests

  • False classifications: stairs became an arch and shallow water became a spring. Current pins are neutral; legacy proposals and quotations remain private evidence with an exact migration backup.
  • Lost source positions: a valid turn-30 Border Weir declaration failed after canon transactions transformed parser input. Original-source rebasing now accepts the exact detached replay while rejecting private or changed sources.
  • A valid knowledge advance rejected: turn 40 named an already reported Bower as newly observed with the same area and southwest bearing. The subsequent core fix reuses its unique public identity and applies the existing monotonic guards. The original trial’s refusal is retained.
  • Wrong-place handle: turn 38 reused a handle after moving to another place. That remains a refusal; changing the interpretation automatically would misfile geography.
  • Missing declarations: the birch stakes, root passage and ritual flagstone still lacked admitted records. Some routes appeared only after movement. The engine cannot claim to have captured what the model omitted.
  • Copied confirmation prose: the model sometimes repeats the engine’s neutral confirmation sentence. This is an unresolved narration-quality issue.

The next admission work

Existing public EXIT declarations are a promising second input to the same admission path. They could recover explicitly declared roads without another model call. This is not safe as a direct copy of stored exits: current EXIT handling can file against the reply’s final location and can accept a directive nested inside private text. A bridge needs original-source validation, source-position scope, explicit outcome policy and deduplication against existing public knowledge. It must not infer bearings, destination identities or geometry from descriptive text.

This would address several documented omissions, but not the dialogue-only birch stakes. Broader rollout still requires a reliable disclosure contract, cross-place identity/relations, evidence-backed legacy promotion and physical-device checks. The existing controls remain intact while those questions are resolved.
