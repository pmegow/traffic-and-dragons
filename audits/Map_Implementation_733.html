Why the old map leaked the hut

The seed 19z1c5t2dzq6 generates hut-1, Stalgind’s Hut, at (350.2,265.6). The party’s approximate centre (400,275) makes it about 63 metres away under the old wild-map scale, inside the 100 metre reveal radius. Distance from an approximate marker was acting as permission to disclose a generated building. The map prompt also declared generated geography authoritative over the narration. Separately, following a location pointer could add a place, but an unchanged pointer did not admit newly described landmarks.

The implemented boundary

  • MapKnowledge prepares detached, bounded disclosure records with stable feature IDs and source receipts. Reads return an allowlisted player projection; observed and reported knowledge stay distinct.
  • Narrated admission accepts a closed MAP_REVEAL declaration only at a committed GM turn. Its readable sentence is published at the declaration’s position, before any later movement. Parser-only, Sync, Table Talk and refused responses cannot publish it.
  • The public adapter builds a fresh schematic only from the player projection. No raw procedural feature is passed to it. The current-place sheet is neutral, unitless, and independent of the old visibility radius.
  • TnD Maps 0.19.0 adds an explicit schematic contract at all five library scales. Unknown-bearing landmarks appear in a separate position-not-established list. Existing generated documents remain unchanged. The game’s first adapter presents one current-place schematic rather than inferring environmental type.
  • Canvas, hit targets, cards, keyboard lists, SVG/export inputs and player-help geography share the public source. A knowledge revision refreshes an open pane even when the party has not moved. Crowded labels produce an actionable warning; their symbols and keyboard entries remain reachable.
  • Explicit activation backs up the entire legacy atlas, validates existing knowledge before any write, and uses a separate public-note dictionary. Save v12 protects world/memory semantics; sheet v11 remains unchanged. Atlas v2 protects the representation.

What is still outside this slice

This is the disclosure-and-projection path, not the complete planned geography engine. Explicit corrections, private world-fact authoring, relation constraints and accepted geometric anchors, split/reparent allocation, landmark-to-location attachment, authored floorplans, multi-sheet navigation and cross-engine geometry work remain. The old atlas is preserved; automatic evidence-backed promotion of established legacy landmarks is not implemented by the conservative activation helper. An unchanged old proper name is never grandfathered solely because the generator drew it.

The GM can still omit a declaration or contradict free prose. The engine does not claim semantic proof from a quoted substring. Live play must measure that compliance, and broader activation remains gated on those results and the remaining migration/device checks. Current maps retain the explicitly tested fallback: an honest sparse schematic, with failures visible.

Owner authorizations: independent implementation/review, live test spend capped at $15, conservative migration with backup, retained story-driven test campaign and memento. No production default activation claimed here.
