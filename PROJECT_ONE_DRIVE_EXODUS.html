Appendix — the game repo optional, separate decision

The game repo (dnd_rpg) is also under OneDrive, but its situation is different: it holds no secrets (API keys live in browser localStorage, never in the repo) and it's pushed to GitHub at every checkpoint — OneDrive is merely redundant, not dangerous. No security need to move it. If you want to move it anyway, bundle it with Known issue #1 (the pending dnd_rpg → traffic-and-dragons folder rename) and mind the gotchas:
  • Do it in Explorer before opening Claude Code, then update the hardcoded paths in .claude/settings.local.json and .claude/hooks/stop-check.js as the first act of the next session (that's the Known-issue-#1 procedure).
  • Claude Code keys its per-project data (session history, memory directory) to the folder path. A moved/renamed folder starts a fresh project profile — the memory index under the old path won't follow automatically and would need to be copied to the new path's project directory.
