**ARCHITECTURE REVISION (2026-07-09) — pipeline of composable POST-PROCESSES, not a monolithic compile.** The transcript dependency (#25/#12) is now DONE, and **Export Narrative shipped v1.229** (`buildNarrativeHtml`, File ▸ Save/Load ▸ 📜 Export Narrative) — transcript → styled HTML with player actions as `.act` blocks and GM prose as `.gm` blocks. That structured, free, deterministic export is **stage 1** and the enabler for everything after it: because the export tags which text is player vs GM in the markup, later passes parse it back into `(action, narration)` pairs and run on the **saved file** — no live campaign/transcript needed, reusable on any exported chronicle. **Stage 2+ = optional, composable LLM passes, each producing a SEPARATE doc (never overwrite the raw chronicle; it stays the honest source of truth):** 

• **Fold player actions** — weave each player action into the following narration so it reads as continuous prose. The core rule (from play): the drop-vs-fold decision is **per-seam, not global** — if the following narration already conveys the action, DROP it; if it assumes the action without showing it (leaving an incongruous hole), FOLD a brief clause in; preserve the GM's actual prose/dialogue, smooth seams only, invent nothing. LLM judgment per transition, not string surgery. 

• **Person conversion (2nd/1st → 3rd)** — recast the immersive second-person "you" (+ first-person player actions) into a third-person novelization ("Vyrindra…/she…", named from the sheet + gender). **LLM, not regex** — the trap is dialogue: narration-"you" must convert but an NPC *saying* "you" must stay. Pairs naturally with a **present→past** tense shift (novel feel). A **taste choice**, not a default — some want immersive 2nd-person, some want a novel about their character. 

**Both passes still need:** chunking (fold/convert a chapter at a time, reassemble — cost + context limits) and the per-seam/per-line model judgment; the post-process framing just isolates all that difficulty behind an opt-in. **Load-bearing constraint:** the export must keep its block structure MACHINE-READABLE (`.act`/`.gm` classes) — flattening it to undifferentiated prose would break every downstream pass.
