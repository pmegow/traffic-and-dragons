# TODO #40 — Core Memory — a permanent, always-injected memory tier for defining moments.

*Full record extracted verbatim from TODO.md (Feature backlog, completed row) on 2026-09-01; the tracker row keeps the TLDR and the verdict. Table pipe escapes (`\|`) are unescaped here; `<br>` breaks became paragraphs.*

**Effort:** M · **Tier:** Fable

## Task

**Core Memory — a permanent, always-injected memory tier for defining moments.** Fills the gap between the tiers that churn/compress (`knowledge[]`/`events[]` cap and evict FIFO — capped at 12/8 by audit E51/E50; `chapters` compress hard) and RAG (verbatim but *probabilistic* and read-side only). No current tier says "this moment is load-bearing — never forget it, keep it in front of the GM." A wedding, a betrayal, the night someone nearly died can age out. `firstEncounter` (write-once "when met", survives merges) and the player's `storyBeats[]` are half-steps; Core Memory is the coordinated generalization. **The design call that decides whether it works: what WRITES to it.** Do NOT lean on the GM's own judgment — every "emit a tag when you decide it matters" system (quest lifecycle, FUTURE_EVENT_RESOLVED) has been spotty. Anchor on **engine-detected triggers** (already visible in `applyMuts`): ① a party member's (or player's) HP crossing below ~10% of max — deterministic, captures near-death peaks, ~trivial hook; ② a companion joining/leaving; ③ a `[RELATIONSHIP:]` descriptor forming/changing to something weighty (Married, Betrayed, Sworn). Softer beats (a "first time", a moment the GM judges momentous) lean GM-authored via an OPTIONAL `[CORE_MEMORY:name|text]` tag — enrichment on top, never the foundation. **v1 shape:** try a **shared party-level** `worldState.coreMemories[]` first (sidesteps "did this companion witness it?"), injected as a small always-present "DEFINING MOMENTS" block; cap **generously** (~25) not never — overflow is a signal the trigger threshold is too loose, not that we need infinite storage; keep each entry one sentence (it costs prompt tokens every turn). **Phase 2:** per-companion attribution ("Bram remembers *his* near-death"). **Design alongside the existing tiers** (lore/knowledge/events/chapters/RAG/storyBeats) so we don't add a 7th uncoordinated store — thematically adjacent to #10 (both are GM-authoritative persistent data). **User note (2026-07-06):** not sold on "party-shared" — build it that way FIRST to validate the mechanic, then revisit per-companion.
