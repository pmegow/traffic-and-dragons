## Task

**Mana pool — replace one-cast-per-spell with a spend-by-tier casting economy.** TLDR: today every known spell is castable exactly once per rest (`used:true`), so a L15 Cleric can heal the party once a day; a mana pool makes casting a resource decision — spam Healing Word or spend big on Spirit Guardians. **Design ruled with the user 2026-07-31 (grew out of the Cleric review):** ① **base mana = the SUM of the known bench's tiers** — self-balancing, scales automatically with picks and tier unlocks, no separate curve table; a player who wants the old behavior can still cast each spell once, but mixing is now legal. ② **Cantrips cost 0** — tier 0 stays at-will, exactly what `cost:"at-will"` already means in the capability bible. ③ **Stat modifier keyed to each class's PRIME CASTING STAT** (a data field per class, not per tradition; user accepted — correction 2026-07-31: this game's Sorcerer prime is INT, not CHA as argued in-session, but prime-stat keying stays strictly more robust than tradition keying either way): **+10% pool per point over 16**. ④ Casting cost = the spell's **capability-bible tier** — canonical, already injected to the GM. ⑤ Opens design room for **mana potions** (user callout). **Second-ring rulings (user, one-at-a-time pass 2026-07-31):** ⑥ **refill = full on Rest only**, nothing between — Sorcerer L7 Sorcerous Restoration is the ONE exception (draft: +25% pool on a short breather; number open) · ⑦ **racial grants stay SEPARATE** — `racial_caps` spells keep their own 1/day recharge, neither add to nor spend from the pool (the pool is the spellbook economy; heritage isn't training) · ⑧ **migration = full pool for everyone** — used flags discarded, one accepted windfall per campaign · ⑨ **overdraw is NECROMANCER-ONLY** — trading life for magic below an empty pool is the class's signature economy (HP-per-point price to be set in its class rows; every other caster hits a hard floor at 0; Sorcerer keeps Overchannel's max-effect-for-blood as a distinct, non-overdraw feature). Implementation trivia flagged as defaults, overridable at review: floor() on the +10% math · sheet/HUD shows `Mana N/M` + per-spell tier costs · strikethrough used-display retires · `[SPELL_DEF:]` overlay spells cost their overlay tier · companion pools use the same formula. **Engine sketch:** the tag vocabulary does NOT change — `[SPELL_USED:name]` stays the one signal; its handler decrements the pool by bible tier instead of flipping a boolean; `restSpells` refills; sheet shows pool. **Blast radius (why Fable):** all 6 caster classes + both third-caster archetypes (Eldritch Knight / Arcane Trickster), companion parity (`checkCompanionLevelUp`, party-sheet "spells available" lines), creation picks (`SPELL_PICK_LIMITS` becomes known-not-castable), sheet UI, save migration for every existing `used` flag, STATE TAGS prompt docs. ⚠ Drift surface (tag handler + char-sheet injection + prompt docs) — design review before code, own session, engine-tested with save-invariant checks. ~~Sequencing: after #72 C6-②~~ (overtaken — costs read from `capabilityLookup`, which is ALREADY engine truth; the class bible was never needed for this).
