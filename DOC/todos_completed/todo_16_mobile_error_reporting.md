**Effort:** S · **Tier:** Sonnet

## Task

**Mobile error reporting** — automatically send an email when a runtime error occurs on mobile (where the console is invisible). Client calls a webhook; webhook sends email to pmegow@gmail.com. Three implementation options: (A) **Google Apps Script** — free, no new accounts, ~20 min setup: create a GAS web app that accepts POST and calls `MailApp.sendEmail()`; (B) **EmailJS** — pure browser JS, 200 free emails/month, ~30 min; (C) **Fly.dev `/api/error` endpoint** — most control, requires server changes + email provider (Resend free tier). Recommendation: Option A. Client side is the same regardless: a debounced `reportError(context, message, detail)` function wired to `window.onerror`, the skeleton catch block, `callGM` error paths, and any other caught errors. Debounce to 1 per 30 s so a cascading failure doesn't flood the inbox.
