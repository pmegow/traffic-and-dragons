Lessons banked

  • Recency beats position. When the GM ignores an instruction because its own recent output says otherwise, change the channel (engine note on the player message), not the spot in the system prompt. Cost: three rounds on the D12 exit bug.
  • A failed fix is a stop signal. User's rule, now standing: don't ship a refined guess — go find the mechanism. Two failures is the outer limit, not the target.
  • Check git log before trusting a snapshot. Block 0 was planned around work that had already shipped.
  • Field verdicts can be design verdicts. The D10 gate didn't pass or fail on the terms it was written — it produced a better rule (D12).
