Quality assessment

  • Accuracy: excellent, externally validated. Every fix was written failing-test-first, and all 8 tests failed on v1.438 exactly as the evidence predicted — the strongest possible check on delegated claims. Every Edit target quoted by an agent matched the working tree byte-for-byte. No fabrication detected anywhere in ~843k tokens of output.
  • Instruction adherence: complete. All six stayed evidence-only (the permitted "gap found / no gap found" factual framing was used correctly, never a verdict), zero repo edits (verified via git status), scratch scripts confined to the scratchpad.
  • Honesty under uncertainty: the standout trait. Brief C labeled its map-suppression probe INCONCLUSIVE and flagged a hand-built pre-state as unproven-by-tag-path; D marked the CAS question UNDETERMINED with the reason; A reported which probes it could not make throw. Nothing was rounded up to certainty.
  • Initiative within scope: high, and it paid. The best finding of the run — scenario (d), new campaigns born marker-less wiping their own correct data — was OUTSIDE brief D's requested matrix; the agent found it while tracing and reported it as such. B expanded to the writer side unprompted; C added producibility probes; F proved the narrator gap reachable (menu gating) rather than merely present.
  • Weaknesses: minor. Verbosity beyond need (~20% of the token bill is prose polish a tighter output format would trim); one agent's "17 files" sweep quietly grew its own scope (correctly, but a stricter brief would have said so); depth occasionally exceeded the question (E's enforcement sketch bordered on design, though it stayed labeled as mechanics).

Economics — measured, not estimated

  • Raw tokens: the prediction held. ~843k Opus + a Fable adjudication/fix share vs. an estimated 400–500k Fable-solo: total tokens roughly 2×, exactly as forecast. Anyone selling delegation as a raw-token saver is wrong.
  • Fable-quota savings: real and large. Fable's share collapsed to brief-writing, six result ingests, verdicts, and the fix package (which any path would have paid). The scarce resource — the one that historically ran out mid-session — was spent almost entirely on judgment.
  • The unforecast win: this was BETTER review, not just cheaper review. 175 tool calls of sweep-and-probe depth — 9 hostile-state probes on one catch block, a 25-site consumer census, live adversarial parse batteries — is more mechanical thoroughness than a solo time-boxed pass would realistically perform. At least three findings (scenario d, the "slain"-invisible class at its true scale, the #92 adopt-path correction) plausibly survive a solo review unfound. Ten confirmed defects from a queue previously believed "probably fine" is the number that matters.
  • Wall clock: all six briefs landed within ~8 minutes of dispatch, in parallel, while the user played. A solo pass is hours, serialized.

Verdict on the workflow

Adopt it as the standard review pattern. The division that worked: Fable writes tight per-item protocols with explicit output contracts and no-verdict rules; Opus executes them in parallel with tools; Fable adjudicates against evidence it can spot-check, and the failing-test-first discipline doubles as the delegation's lie detector. Keep verdicts and drift-surface fixes on Fable — nothing in this run argues for relaxing the 2026-07-09 decree, and the run's own value came precisely from the judgment layer having pristine evidence to judge. Two refinements for next time: ① a terser mandated output format (tables + quotes only, prose budget ~500 words) to cut the ~20% verbosity tax; ② briefs should state scope-growth rules explicitly ("sweep whatever the question touches; say so when you do") since the agents' instincts there were good but unauthorized.
