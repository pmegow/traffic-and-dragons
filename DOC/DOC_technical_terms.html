Browser & plumbing

base64
A way to write any data as plain letters and numbers, so a whole save can be copied through a text-only channel and rebuilt.
cache-busting
Adding a random tag to a web address so the browser grabs the real newest file instead of an old saved one.
cache-first
The app shows its saved copy first (instant), only checking the network for a new version. Fast — but needs a version bump to refresh.
CORS Cross-Origin Resource Sharing
The browser's rule about which outside servers a page may call. It blocks the call unless that server says "you're welcome here."
DOM Document Object Model
The live map of everything on the page. Change the DOM and the screen changes; "repaint the DOM" just means redraw what you see.
ES5
The old, super-compatible flavour of JavaScript we stick to so the game runs anywhere with zero build step. No modern shortcuts allowed.
IIFE Immediately-Invoked Function Expression
A blob of code wrapped so it runs once, right away, and keeps its guts private. How the playtest tool installs itself.
IndexedDB
A much bigger browser box (hundreds of MB) we can move into if localStorage runs out of room.
localStorage
A small (~5MB) box in your browser where the game stashes saves and settings as text. Fill it and saving fails — the "storage full" toast.
LZ LZ-string
Our built-in zip: squeezes the story log ~5× smaller before storing, so long campaigns don't blow the storage limit.
OAuth
Logging in through GitHub without handing us your password — GitHub vouches for you and gives us a temporary token.
SW Service Worker
A background helper that keeps a copy of the app so it opens instantly and works offline. We bump its version so it refreshes each release.

AI & the prompt

ELI10 Explain Like I'm 10
Describe what a thing does in plain words, no jargon. What this whole page is doing.
GM Game Master
The AI playing narrator and referee. It writes the story and hides bookkeeping codes in its reply for the engine to read.
MTok million tokens
The unit model prices are quoted in — e.g. Haiku costs $1 per million tokens read in, $5 per million written out.
prompt caching
Paying full price once for the unchanging part of our instructions, then ~10% each turn after. Big savings — the reason we split the prompt.
RAG Retrieval-Augmented Generation
When old people or places come up, we dig the exact past scene out of the full log and show the AI — so it "remembers" turn-150 events at turn-300.
stable / volatile
The two halves of the AI's instructions: STABLE never changes (cached cheap), VOLATILE is this turn's live state. Leaking state into stable kills the discount.
state tags
Hidden codes like [HP:-5] the GM sprinkles into its reply. The engine reads them to update your sheet, then strips them from view.
token
The chunk the AI counts words in (~¾ of a word). Everything is billed and size-limited in tokens.

Words we coined (project jargon)

act / arc
Act = a big chapter of the campaign; arc = a step inside it. Finishing one flips a status flag and advances the story.
anti-drift injection
Re-feeding the AI the true current facts (quests, sheet, spell rules) every single turn, so it reads from data instead of its faulty memory.
blueprint
A pre-made campaign kit — outline, NPCs, places, rules — minus any character. Load it and play someone else's adventure with your own hero.
corpus
The pile of raw turns collected from a playtest run — the evidence we grep through to judge quality and hunt drift.
cutover
The day replacement code stops shadowing and becomes the real thing — like traffic switching to a new bridge after load-testing beside the old one.
dnaHint
A one-line "how to run this bit" note that keeps each arc in the author's voice instead of drifting into generic procedure.
drift
The core enemy: the AI slowly reinventing a fact or rule over many turns — a spell's range creeping up, a character's backstory quietly mutating.
fold
Weaving a player's action into the following narration so a story reads smoothly, instead of "I do X." then "X happens."
harness
A script that auto-plays the game for many turns (real AI calls) so we can stress-test and gather a corpus without hand-clicking.
money test
The real question a feature exists to answer, tested under pressure — e.g. "does the AI actually obey the spell bible mid-fight?"
nudge
A soft line slipped into the AI's instructions to push it toward doing something (close the act, stay on plot) without hard-forcing it.
over-rail
Steering the story so hard the player's choices stop mattering. The thing our pacing nudges are deliberately careful NOT to do.
palimpsest
Something written over so many times old and new layers mix — like a 300-turn save built across many engine versions, part current, part fossil.
satellite page
A standalone HTML page opened on its own (the Blueprint Designer, this glossary) — NOT part of the cached main app.
shadow mode
Running replacement code on a throwaway copy of the data while the old code stays in charge — differences get logged, players see nothing.
skeleton
The campaign's 3-act outline — acts made of arcs — that the story follows. From a blueprint, or auto-generated at the start.
soak
Letting new code run quietly alongside the old during real play, comparing results every turn until enough clean evidence accumulates to trust it.
spine
The authored main plot of a loaded adventure. "Stay on the spine" = tell that story, don't wander off into a made-up side-plot.
tail retention
After summarizing, keeping the last few exchanges word-for-word so the AI doesn't suddenly "forget" what just happened.
teeth
A rule the ENGINE enforces itself so we don't trust the AI to remember — e.g. "all objectives done → nudge it to close the quest."
the bible capability_bible
One master list of what every spell and ability actually does, fed to the AI each turn so it can't rule them differently every time. Anti-drift.
thrash
A system spinning uselessly — like the memory summarizer firing every two turns and never getting ahead. A sign something's tuned wrong.

Save & state

.tnd
A save file — your whole campaign as one JSON blob you can export, back up, and reload.
memory
Long-term notes the game keeps between sessions: what NPCs know, places visited, lore, big decisions, chapter summaries.
sessionLog
The recent back-and-forth actually sent to the AI this session. Trimmed down whenever the memory summarizer runs.
summarize
When the recent log gets long, the AI compresses it into a "chapter" and files the facts, so the game remembers without re-sending everything.
transcript
The complete, in-order log of every narrated turn. The source for reloading the story, RAG recall, and the keepsake export.
worldState
The one big live object holding everything about the current game: your character, the world, NPCs, quests, combat, and the turn counter.

Characters

companion / charSheet
An NPC travelling with you who has a full character sheet (their charSheet) and levels up alongside your hero.
NPC Non-Player Character
Everyone else the AI runs — allies, enemies, shopkeepers, the villain.
PC Player Character
The character you control — the "you" the story is told to.
racial_caps
A race's abilities pointed at the shared bible instead of re-written on the race — so "what Darkvision does" lives in exactly one place.

Infra & releases

APP_VERSION / CACHE
Two stamps we bump every release so you (and we) can confirm the newest code is actually live and the old cache got cleared.
Cloudflare Pages
Where the app itself is hosted — plain static files, auto-published every time we push to the main branch.
Fly.dev
Where the sync server lives — it handles logins and stores your cloud saves so a campaign follows you across devices.
GAS Google Apps Script
A tiny program hosted free inside your Google account. Ours receives the game's crash reports and emails them to you.

Skills

Rituals we kept re-explaining from scratch each session, written down once so Claude runs them the same way every time. Each lives in .claude/skills/<name>/SKILL.md.

/bugs
Triage for crash reports the game emailed itself — pull new ones, investigate a chosen one, then fix it. Use it when: reports have piled up and you want them filed, explained, or fixed. Say: /bugs sync, then /bugs investigate B7, then /bugs act B7.
/field-finding
Turns "the GM did something wrong in my game" into a proven cause and a backlog row. Never edits code. Use it when: you saw it happen while playing, and there's no crash report — just your eyes on a turn. Say: /field-finding my healing potion vanished from the pack around t612. A turn number makes it far stronger.
/playtest
Auto-plays real turns against a throwaway hero, then judges the corpus for broken rules, missing state tags, and prose drift. Use it when: a risky change needs proof it survives real play. Costs real API money — it asks first past ~25 turns. Say: /playtest run 20, then /playtest audit; /playtest recover rescues a run whose window you closed.
