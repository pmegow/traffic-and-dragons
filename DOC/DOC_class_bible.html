Part II — Decisions (all RULED)

C1 — Schema: one entry per class, a per-level dict, archetypes nested with their own levels. STANDS (R1) 
CLASS_BIBLE = { "Rogue": {
  id:"Rogue", hd:8, prime:"DEX", gear:"…", desc:"…",
  statPriority:["DEX","INT","CON","WIS","CHA","STR"],
  abilities:[ "Sneak Attack", "Evasion", "Lockpick" ],   // names -> capability_bible
  skillSeeds:[ "stealth", "lockpicking" ],               // C5: creation-only Familiar seeds
  spellTiers:{ 2:5, 3:7, 4:9, 5:11, 6:15 },              // C2: tier -> unlock level (casters)
  levels:{                  // CLASS features by level — names -> capability_bible
    2:{features:["Cunning Action"]}, 5:{features:["Uncanny Dodge"]}, … },
  archetypes:[ { id:"arcanetrickster", nm:"Arcane Trickster", desc:"…",
    spells:{...},           // the ARCH_SPELLS grant, folded in
    levels:{ 3:{features:["Mage Hand Legerdemain"]}, 6:{…}, 10:{…},
             14:{…}, 18:{…}, 20:{features:[""]} }
  }, … ] } }
Features become named capability_bible entries where they are actives or lookup-worthy passives (the racial_caps precedent) — which also fixes the nm:"Lv9" naming bug structurally. Pure-flavor passives may stay prose. A coverage-guard test blocks a bible name with no capability entry from shipping.
C2 — Spell growth = PICKS at tier-unlock levels. RULED 2026-07-27
Reuse the creation spell-picker at each unlock level (SPELL_PICK_LIMITS-style pick counts, per tier). Unlock rhythm for full casters under the L20 grid: T2@L5 · T3@L7 · T4@L9 · T5@L11 · T6@L15. Necromancer T4 and the Arcane Trickster's Oubliate finally become reachable by progression. Spell content caps at T6 as authored scope — the tier system stays open-ended beyond that (GM-grantable, per the standing CLAUDE.md note), but T7+ is not part of the #72 authoring bill. Half-casters (Ranger/Paladin) run one tier behind at each step; exact per-class pick counts are template-iteration material.

C5 — Skills: creation-only familiarity seeds. RULED 2026-07-27
Each class seeds Familiar rank (1 success) in 2-3 signature skills at creation — skillSeeds in the schema (Rogue: Stealth, Lockpicking; per-class lists are template material). One-time seed at confirmChar; the usage-driven system is otherwise untouched, and existing saves are untouched (seeds are creation-only — the C6 invariant holds; no retroactive grant). Per-level skill grants stay explicitly out of scope.
C6 — Landing sequence (ruled 2026-07-18) + the invariant. RATIFIED
① classDef(id) becomes THE lookup, collapsing ~30 hand-rolled loops — pure refactor, shippable alone. ② The backing store swaps to CLASS_BIBLE inside that one helper. ③ CLSS deleted. Invariant test at every step: an existing character's derived values must not move — load the live save before/after and assert identical hit die, features, archetype list, stat priority. Mid-campaign characters must not retroactively gain or lose anything; new grants apply only at their NEXT level-up (Ammut at L9 sees the new world first at L10 — the archetype row — then T5 picks at L11). ⛨ Drift surface at step ② onward: Fable builds those steps.

Part II-b — The archetype-level rubric (defined 2026-07-27, v1.465)

Why a rubric at all: 27 archetypes × 6 rows = 162 authored features. Without a defined job per row that is 162 arbitrary decisions and the classes drift apart in feel. Each archetype row now has a stated purpose, shown in the editor at the point of authoring — class rows deliberately have none, because the class is the chassis and the archetype is the character.
RowJobTest for "is this the right feature here?"
L3 — IDENTITYThe signature thing that makes this archetype itself; for the caster archetypes, spellcasting comes online (T1)Could a player describe their character with just this one line?
L6 — REFINEMENTDeepen the L3 identity — a second application, a resource, a real upgradeDoes it read as "more of the thing I chose"?
L10 — REACHA NEW capability that broadens what the archetype can do, rather than deepening L3 (third-caster T2)Does it open a situation that was closed before?
L14 — MASTERYThe identity becomes reliable — remove a limitation, or scale the core trick (third-caster T3)Does the thing that used to sometimes fail now land?
L18 — APEXPowerful and campaign-shaping, one step below the capstone (third-caster T4)Would a GM plan around a party member having this?
L20 — CAPSTONEOne dramatic defining ability; the thing the character is remembered forIs it worth 355,000 XP?
C7 — Caster ARCHETYPES are third casters, keyed to their own spine. DEFINED 2026-07-27
The gap this closes: Arcane Trickster and Eldritch Knight both carry spell benches but had no unlock schedule — spellTiers was generated only for the six full/half-caster classes, so under the C2 picks ruling nothing said when an Arcane Trickster earns T2, and its bench (which already reaches T4 / Oubliate) stayed unreachable by progression.
