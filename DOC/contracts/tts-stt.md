### tts.js

Status: ✅ Active

Text-to-speech: `TTS` module with a `TTS_PROVIDERS` table (mirrors the LLM `PROVIDERS` shape): `server` / `piper` (local WASM, offline, $0 — #41; vendored at `/vendor/piper/`, voices cached in OPFS) / `native` (browser speechSynthesis). Engine selection is RESOLVED, never stored — there is no picker ([history](DOC/CLAUDE_HISTORY.md#ttsjs--provider-evolution)). **Server tier (#90 M1):** `TTS_LADDER = server → piper → native` — a connected player's narration synthesizes on the self-hosted **`tnd-tts` Fly app** (§22); `getEngine()` resolves `"server"` when connected+healthy, else `"piper"`. Any server unit failure hands the read's remainder down the ladder via the queue + a 60s retry memo (degrade toasted once per session). Self-hosting is why the #84/LiveKit objection doesn't apply ([DOC/Research/liveKit_findings.html](DOC/Research/liveKit_findings.html)). The per-item **downgrade-to-native** ladder survives below all of it (`_piperOk` can drop ONE item without changing the engine); the work-budget governor meters ONLY the local Piper tier and remains the offline tier's guardian forever. Shared text-prep (`normalizeForTTS`/`splitSentences`), queue/scheduler, voice bank. **NPC casting (#174):** every roster NPC auto-casts from the starred bench on first speech (sheet gender → pronouns → full bench); the stable pick persists on the NPC record until a generated sheet inherits it. **Gemini tier (#41, v1.646; opt-in, default OFF — bills the player's own gemini key):** `TTS_LADDER` is now `gemini → server → piper → native`; Google prebuilt voices via `generateContent` AUDIO on `gemini-3.1-flash-tts-preview`, consecutive same-voice units GROUPED per call, narrator/direction prefs + ▶ Test audition, degrade window 60s. **#41b (v1.653): the synthesis CONVEYOR** — `_geminiConveyor` runs up to `GEMINI_TTS_PREFETCH`=3 groups concurrently, delivers strictly in order (`started−taken<depth` is THE bound: memory, quota burst, and skip-waste together; abort-on-skip cancels in-flight billing); `GEMINI_TTS_FAST_START_CH`=220 caps group 1 for the cold open; `_geminiTimeoutMs` scales deadlines with group length. **#41c (v1.654):** 429s are QUOTA windows, not blips — patient backoff [5s,15s,30s] honoring the body's `RetryInfo.retryDelay`, absorbed by the conveyor's own runway; skip-aborts recognized mid-wait (the deadline timer self-identifies; #41d makes the sleeps themselves abort-raced) so long retries can’t bill a dead read. **#41d (v1.655):** a RetryInfo hint over 45s = a CLOSED quota — degrade immediately with Google’s number and extend the degrade window to it (capped 10 min) instead of re-probing every 60s. **#41e (v1.656):** prime-the-pump — the first schedule holds until the opening seam is covered (group 2 landed / 8s contiguous lead / 8s hold cap), so a short opener + early voice change can’t start-then-hang. **#41f (v1.659): the in-family MODEL LADDER** — `GEMINI_TTS_MODELS` = 3.1 → `gemini-2.5-flash-preview-tts` (Google documents ONE shared 30-voice list, so a fall keeps the entire cast; 2.5 is half the paid price). Free-tier quota buckets are PER-MODEL: a closed-quota 429 closes ONE bucket (per-model memo, honors Google's hint clamped 60s–10min, never shrinks) and the SAME group retries on the next rung mid-read; later fetches skip closed buckets without probes; only an all-closed ladder degrades the engine, window sized to the EARLIEST reopen; ▶ Test/opt-in clear the memo. Battery: dev/tests-41f-gemini-model-ladder.js (scripted fetch, in run-standalone-suites). Streaming remains the deliberate later step (conveyor slots become streams — rung 0 only; 2.5 can never stream).

### stt.js

Status: ✅ Active

Speech-to-text input: `STT` module with **two independent paths**. ① **Native** — Web Speech API (`webkitSpeechRecognition`, zero-dependency): Chrome/Edge desktop + Android Chrome; NOT Firefox; iOS Safari has NO SpeechRecognition at all. ② **Cloud fallback** — when native is absent AND an OpenAI key is on file, `MediaRecorder` captures the utterance and OpenAI transcribes it (#113 §4: `gpt-4o-mini-transcribe` primary, loud `whisper-1` fallback; `sttBiasPrompt()` roster/place/quest vocabulary on every request; WebAudio silence endpointing 1.5s/45s). **This is what makes the iPhone Safari / Car Mode path work** ([history](DOC/CLAUDE_HISTORY.md#sttjs--the-stale-doc-lesson-84)). A fully separate code section below the native one, so native behavior stays byte-identical wherever native exists; `isSupported()` gates the mic button on EITHER path. Both paths run the final transcript through **`sttCorrectNames`** (helpers.js) — roster-phonetic correction for fantasy proper nouns. Prefs: language/auto-send (`tnd_stt_lang_v1`/`tnd_stt_autosend_v1`), Car Mode auto-listen (`tnd_car_autolisten_v1`, default ON). Notifies Car Mode via global `carNotify(kind,text)`, always behind a `typeof` guard. ⚠ **Transcription cost rides the PLAYER's own key** — decisive in declining LiveKit. **#77 confirm gate (v1.548):** per-utterance confidence (`sttLogEvent` ring, read via `sttLogAll()`) feeds `sttSuspicion` (helpers.js), gating the AUTO-SEND path only — Car Mode speaks "I heard: … — send it?" with spoken yes/no/redo (`parseConfirmCommand`; the confirm interceptor sits ABOVE carVoiceCommand/busy-park/<3-char gates), non-car auto-send holds + amber-flags the field; File ▸ Admin ▸ 🛡 toggle, default ON; nothing touches sessionLog/transcript until confirmed. Invented tags (the [MANA:-1] leak) are display-stripped by cleanTxt's unknown-tag catch-all
